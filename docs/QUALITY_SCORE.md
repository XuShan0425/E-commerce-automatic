# 质量评分

> 最后更新: 2026-05-31 | 追踪各模块的代码质量和文档覆盖度

## 评分维度

每个模块按以下维度评分 (1-5):

- **测试覆盖 (T)**: 单元测试 + 集成测试覆盖率
- **文档完整 (D)**: 代码注释 + 架构文档是否反映真实行为
- **边界安全 (S)**: 输入校验、错误处理、降级路径
- **可观测性 (O)**: 结构化日志、指标、健康检查
