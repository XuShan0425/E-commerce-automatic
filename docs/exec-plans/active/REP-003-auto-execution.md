# REP-003: 安全自主执行

## 状态

- **创建**: 2026-06-01
- **状态**: 进行中
- **优先级**: P1
- **分支**: `codex/rep-003-auto-execution`
- **依赖**: REP-002 (管线质量与可观测性)

## 合并来源

本 EPIC 整合了以下原碎片 EPIC:

| 原 EPIC | 原优先级 | 说明 |
|---------|---------|------|
| EPIC-034 边界条件检查器 (执行门) | P1 | 硬边界阻止 + 软边界确认流程 |
| EPIC-035 广告出价自动执行 | P1 | Playwright 自动出价调整 |
| EPIC-036 推广活动自动管理 | P1 | 活动级开启/暂停/关闭 |

以及技术债务 TD-003 (adjuster.py DOM 选择器占位符)。

## 目标

实现广告管理的全自动执行链路: AI 决策 → 边界校验 → Playwright 执行 → 操作日志。将 `adjuster.py` 的占位符 DOM 选择器替换为真实速卖通选择器，确保安全边界硬性执行。

## 背景

当前 `adjuster.py` 的 DOM 选择器均为 TODO 占位符，系统无法执行任何实际广告操作。边界检查逻辑未与执行引擎集成，存在安全风险。

## 非目标

- 不涉及 Dashbaord / 日志 / 警报前端 (REP-004)
- 不涉及联盟营销或竞品数据 (REP-005)
- 不改变 AI 决策逻辑

## 关键依赖

- REP-002 完成确保测试覆盖和日志记录基础设施
- 真实速卖通 CSP 环境用于 Playwright 选择器验证

## 任务分解

### TASK-003-1: Adjuster 真实选择器

- 替换 `adjuster.py` 中所有占位符选择器
- 覆盖: 出价调整、预算更新、广告类型切换、活动开启/暂停/关闭
- 通过 CDP 或在真实速卖通暂存环境通过 Playwright 验证

### TASK-003-2: 执行引擎 E2E

- 将 `execution_engine.py` 连接到调整器
- 实现: 决策摄取 → 边界检查 → Playwright 操作 → 前后快照 → 操作日志
- 验证 dry_run 模式正确工作

### TASK-003-3: 硬边界自动停止

- ROI 连续 7 天为负 → 停止该 SKU 广告 + 生成分析报告
- Cookie 失效 → 停止所有操作 + 警报通知
- 采集异常 → 跳过本次执行 + 记录日志

### TASK-003-4: 软边界确认流程

- 关闭推广活动时暂停执行
- 生成关闭说明文档 (数据摘要、理由、预计影响、替代方案)
- 等待人工确认后执行

### TASK-003-5: 活动管理

- 扩展 adjuster 支持活动级操作 (开启/暂停/关闭)
- 活动状态查询 API
- 活动管理操作日志记录

### TASK-003-6: E2E 自动化测试

- 使用 Playwright 验证至少 1 SKU 的完整执行循环
- 记录成功率

## 验收标准

1. `adjuster.py` 在真实速卖通 CSP 环境通过 Playwright E2E 测试
2. `execution_engine.execute_decision()` 对所有决策类型返回正确结果
3. 硬边界自动阻止执行并正确记录
4. 软边界触发待处理警报，不自动执行
5. 1 SKU 可完成采集→利润→AI→边界→执行→日志全闭环
