- 切换 Tab 不会同步日期选择
- 切换 Tab 后，新 Tab 加载的是其默认日期范围的数据

## 备注

1. **关于 stealth.js**: SYCM SPA 对 `navigator.webdriver` 等属性修改敏感。注入 stealth.js 会导致 SPA 无法加载（页面标题变为 "Seller Center" 而非 "单品分析"）。**使用 SYCM 时不应注入 stealth.js**，仅使用 UA/Viewport 伪装即可。
2. `<input>` 日期选择器的 `getBoundingClientRect()` 返回 `width=0, height=0`，说明这些输入框可能在 DOM 中但不占用视觉空间（被日期选择器组件库隐藏）。实际点击事件应通过其父级 `.ant-picker` 容器触发。
3. 数据加载依赖多个并发的 mtop API 请求，等待所有请求完成后约 2-3 秒数据表格才会渲染。自动化采集时需使用 `page.wait_for_response()` 或 `page.wait_for_selector('table')` 确保数据已加载。
4. 存在额外的"价格" Tab（共 6 个 Tab，非 5 个），阶段二中需覆盖。
