# 产品原则

> 最后更新: 2026-05-31 | 用于指导 AI 决策和功能开发

## 核心信念

### 1. 利润优先于流量

广告优化的首要目标是**净利润最大化**，而非曝光量或点击量。一个 ROI 为负的高流量商品正在烧钱。

对 AI 决策的含义：当 `current_roi < 0` 持续 7 天时，必须 `stop_ad`，即使该商品有高点击率。

### 2. 数据驱动，但不盲从

AI 决策基于数据，但需要认识到数据的局限性：
- 广告 API 返回的数据有 2-4 小时延迟
- 速卖通后台数据可能因反爬策略不完整
- 单日异常波动不应触发大幅调整

对 AI 决策的含义：`confidence` 字段应反映数据质量。数据不完整时降低 confidence，触发 `requires_confirmation`。

### 3. 安全操作优于激进优化

一次错误的广告暂停（漏掉赚钱机会）的代价远小于一次错误的广告加价（烧钱）。

对 AI 决策的含义：
- 不确定时倾向于 `no_action` 或 `requires_confirmation`
- `stop_ad` 应该是可逆的（暂停而非删除）
- `adjust_price` 需要更高 confidence 阈值

### 4. 渐进式优化

小幅、高频的调整优于大幅、低频的调整。系统设计为每 30 分钟运行一次采集-分析循环。

对 AI 决策的含义：单次调价 ≤ 5%，等待下一轮数据验证效果后再继续。

## 什么是"好的"广告决策

一个合格的 AI 决策应该满足：

1. **有明确的数据依据** — reasoning 字段引用具体数字（如 "ROI 从 1.2 降至 0.8，持续 3 天"）
2. **在边界约束内** — 通过 `boundary_checker.py` 的全部硬边界
3. **confidence 合理** — 数据充足的常规情况 ≥ 0.7，数据不足时 ≤ 0.5
4. **可逆** — 决策可以被回滚（暂停的广告可以重启）

## 用户意图优先级

当功能存在冲突时，按以下优先级决策：

1. **用户明确指令** (手动暂停、手动调价) > 一切自动化
2. **安全边界** (硬边界) > AI 决策
3. **AI 决策** > 默认行为 (no_action)
4. **软边界警告** 不阻止执行，但记录日志

## 功能哲学

- 前端是**控制面板**，不是**数据浏览器** — 每个页面应该有明确的行动号召
- 错误信息应该告诉用户**该做什么**，而非仅仅描述错误
- 默认值应该安全（dry_run 用于测试，global_stop 用于紧急情况）
- 日志不是给人一行行看的 — 它们是为智能体搜索和分析准备的
