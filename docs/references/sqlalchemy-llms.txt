# SQLAlchemy 2.0 Async 参考

> 为智能体提供的 SQLAlchemy 模式速查。版本: 2.0+

## 模型定义

```python
from sqlalchemy.ext.asyncio import AsyncAttrs
from sqlalchemy.orm import Mapped, mapped_column
from App.core.database import Base

class MyModel(AsyncAttrs, Base):
    __tablename__ = "my_table"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(200), nullable=False)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now()
    )
```

## 异步查询

```python
from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

# 单条查询
result = await db.execute(select(Model).where(Model.id == id))
record = result.scalar_one_or_none()

# 列表查询
result = await db.execute(
    select(Model).where(Model.is_active == True).order_by(Model.created_at.desc())
)
records = result.scalars().all()

# 聚合
result = await db.execute(select(func.count(Model.id)))
count = result.scalar()

# 写入
db.add(instance)
await db.commit()
await db.refresh(instance)
```

```python

data: Mapped[dict | None] = mapped_column(JSONB, default=dict)
```

## 会话管理

```python
# 通过 FastAPI 依赖注入
async def get_db() -> AsyncSession:
    async with async_session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
```

## 注意事项

- 必须在 async 函数中使用 `await`
- `session.commit()` 后对象属性可能过期 (`expire_on_commit=False` 已设置)
- 避免在 session 外部使用已加载的对象关系
- 大批量写入使用 `add_all()` + 单次 `commit()`
