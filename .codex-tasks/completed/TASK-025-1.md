## Goal

优化项目自动化流水线脚本（`scripts/agent-verify.py` 和 `scripts/lints/`），修复隐式 Bug，统一工具函数，增强跨平台健壮性和可维护性。

## Background

现有自动化脚本存在以下问题：

1. **`agent-verify.py::run_cmd` 不接收 `cwd` 参数** — `check_typescript_build()` 调用 `run_cmd(["npx", "tsc", "--noEmit"], timeout=60, cwd=str(frontend_dir))` 但 `run_cmd` 函数签名为 `def run_cmd(cmd: list[str], timeout: int = 30)`，`cwd` 参数被静默忽略，TypeScript 编译检查始终在错误目录执行。

2. **`run_cmd` 工具函数重复** — `scripts/agent-verify.py`、`scripts/post-task.py`、`scripts/lints/run-all.py` 都定义了相似的 `run_cmd` 实现，违反 DRY 原则。

3. **缺少 shell 命令超时区分** — 部分长时间运行的 Lint 检查没有超时机制。

4. **错误信息不够详细** — 当命令失败时，不显示退出码或截断输出。

## Scope

### 1. 共享工具函数

- 创建 `scripts/utils/command.py` 模块，包含统一的 `run_cmd` 和 `run_python_script` 函数
- 支持 `cwd`、`timeout`、`env` 参数
- 支持结构化错误输出（exit code + stdout + stderr）
- 优化类型注解

### 2. 修复 `agent-verify.py`

- `check_typescript_build()` 中的 `cwd` 参数正确传递
- 导入共享 `run_cmd` 替代本地定义
- 添加 `--help` 和更清晰的参数说明
- 优化证据保存格式

### 3. 优化 `scripts/lints/run-all.py`

- 导入共享 `run_cmd` 替代本地定义
- 添加并行检查支持（可选，通过 `--parallel` 参数）
- 增加整体超时限制
- 优化输出格式

### 4. 优化 `scripts/post-task.py`

- 导入共享 `run_cmd` 和 `run_python_script` 替代本地定义
- 增强错误恢复能力
- 统一时间戳格式
